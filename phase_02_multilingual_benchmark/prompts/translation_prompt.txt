This run uses a supervised sequence-to-sequence translation checkpoint, not a chat API.
There is no natural-language system/user prompt and no sampling temperature.

Model: hari31416/indictrans2-en-indic-1B-ONNX-int8
Revision: 659294a223583c6bc8686facb8f0dc15d593b2d1
Base model: ai4bharat/indictrans2-en-indic-1B (original base revision unspecified)
Provider: local ONNX Runtime 1.27.0, CPUExecutionProvider
Format: community dynamic INT8 ONNX; no repository Python is executed
Source tag: eng_Latn
Target tags: hin_Deva (hi), mar_Deva (mr), ben_Beng (bn), tam_Taml (ta)

Actual conditioning procedure:
1. IndicProcessor(inference=True).preprocess_batch([source_segment],
       src_lang="eng_Latn", tgt_lang=TARGET_TAG)
2. tokenizers.Tokenizer.from_file(tokenizer_src.json), with truncation/padding disabled.
3. Run encoder_model.onnx, then decoder_model.onnx for the first token and
   decoder_with_past_model.onnx for subsequent tokens. Reuse all four decoder/
   encoder key/value tensors per layer. Select the highest-scoring token at
   every step (greedy, num_beams=1, do_sample=false).
   Start token is 2; stop on a newly generated EOS token 2. The total length
   budget is 256, including the start token (at most 255 newly generated tokens).
   Reaching this budget without EOS creates a mandatory review flag.
4. Decode generated IDs with tokenizer_tgt.json, skip_special_tokens=True.
5. IndicProcessor.postprocess_batch(decoded, lang=TARGET_TAG)

Translate context, question and every gold-answer string independently.
Chunk contexts by English sentence boundaries, then whitespace if needed, using
the actual preprocessed tokenizer length and a 256-token input budget. Retain all
normalized source words. Join translated segments with one space. Preserve the
decoded text, token IDs, segment boundaries and postprocessed output in raw logs.
Do not add independently translated answers to the context. Exact alignment is a
separate data-validation step; missing or ambiguous matches require human review.

No Gemma/Gemini outputs or original API prompts were supplied or verified here.
This procedure was executed in the approved 20-record pilot on 18 November 2026. All translations completed; only 2/20 gold answers aligned to unique exact context spans. No human quality ratings were supplied.
The earlier 200M/five-beam plan was never executed. This INT8 backend uses CPU,
batch size 1 and greedy decoding following the inspected exporter interface:
https://github.com/Hari31416/indictrans2-onnx-export/blob/c488d66bd1a59bcd419d246e6c2b85c17384d9bc/src/translate.py
Out-of-dictionary token IDs and non-finite logits fail explicitly; they are not
silently mapped to unknown tokens. No speed, memory or quality result is claimed.
